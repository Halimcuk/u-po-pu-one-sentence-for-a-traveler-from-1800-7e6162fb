One road holds every post office, library, and market on earth side by side, and a letter dropped in any box reaches its door before you have let go of it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

The program writes the one-sentence explanation to `entry.txt` in the output directory (1–200 characters, a single sentence, every word one a person in 1800 could know).
